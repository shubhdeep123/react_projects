A curated collection of React.js projects built while learning and exploring modern frontend development concepts. This repository demonstrates practical implementations of React fundamentals, reusable components, custom hooks, state management, performance optimization, and real-world UI patterns.

- Event Handling

- React Hooks

  - Custom Hooks

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/shubhdeep123/react_projects.git
```

Navigate to any project

```bash
cd react_projects/project-name
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
